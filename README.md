# 🐍 SnakeShop

A modern and responsive e-commerce web application built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**.

SnakeShop is designed as a clean and scalable online shopping interface with a focus on modern UI, responsive layouts, reusable components, and a smooth user experience.

## ✨ Features

- 🛍️ Modern e-commerce interface
- 📱 Fully responsive design
- 🎨 Clean and modern UI
- 🧩 Reusable React components
- ⚡ Fast performance with Next.js
- 🌙 Modern styling with Tailwind CSS
- 🧱 Component-based architecture
- 🎯 Type-safe development with TypeScript
- 🔎 Product-focused shopping experience
- 📐 Responsive layouts for desktop, tablet, and mobile

## 🛠️ Tech Stack

- **Next.js 16**
- **React 19**
- **TypeScript**
- **Tailwind CSS 4**
- **shadcn/ui**
- **Lucide React**
- **Base UI**
- **ESLint**
- **pnpm**

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- pnpm

### Installation

Clone the repository:

```bash
git clone https://github.com/danial137/snakeshop.git
```

Navigate to the project directory:

```bash
cd snakeshop
```

Install dependencies:

```bash
pnpm install
```

### Run the Development Server

```bash
pnpm dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## 📦 Available Scripts

| Command | Description |
|---|---|
| `pnpm dev` | Start the development server |
| `pnpm build` | Build the application for production |
| `pnpm start` | Start the production server |
| `pnpm lint` | Run ESLint |
